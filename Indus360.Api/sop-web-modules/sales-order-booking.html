Sales Order Booking

Steps

  1. Select your Client
  2. Select your Item
  3. Enter the Order
  4. Click on the Add (+)
  5. Click on the Next button.
  6. Select the Sales Order Prefix
  7. Enter Purchase Order Number
  8. Select HSN Group
  9. Select Delivery Date
  10. Select Job Type
  11. Select Job Reference
  12. Select Job Priority
  13. Click on the Save button
  14. Click on the OK button
