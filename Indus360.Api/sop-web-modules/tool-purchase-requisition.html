Tool Purchase Requisition

Definition

A Tool Purchase Requisition is a formal document used to request the purchase of specific goods within an organization. It includes details like item descriptions, quantity, and required date as the starting point for the procurement process.

Steps

  1. Click on the Create Requisition Button
  2. Click on the Add Item
  3. Search and Select Items (same process as for multiple item selection) This is a combined inventory for all types of materials Like Paper, Reel,
  4. Click on the Next Button
  5. Enter the required quantity
  6. Click on the Save button
  7. Click on the YES Button
