Tool Purchase Order Approval

Definition

A Tool Purchase Order approval is the process through which a request for goods, services, or resources is reviewed and authorized before any purchase or action is taken.

Steps

  1. Search and Select Items
  2. Click on the Purchase Order Details
  3. Click on the Approve Button
  4. Click on the Yes Button
